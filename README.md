# Freedom V4: Sea Shanties

A Minecraft 1.21.1 (NeoForge) modpack: Create, ships, seas and seasons on a tropical island world.
It **updates itself every time you press Play** in Prism Launcher.

## Install (once, about 5 minutes)

1. Install **[Prism Launcher](https://prismlauncher.org/download/)** (free, Mac and Windows) and sign in with your Microsoft account.
2. In Prism click **Add Instance → Import**, paste this link and click OK:

   ```
   https://raw.githubusercontent.com/Cha0sslay3r/seashanties-pack/main/prism/Freedom-V4-Sea-Shanties-Prism.zip
   ```
3. Select the new instance and press **Launch**. The first launch downloads all the mods (a few minutes). After that, only changes are downloaded.

The server is already in your multiplayer list.

## Memory
The instance uses 5 GB. On a 16 GB computer you can raise it to 6–8 GB: **Edit → Settings → Java → Maximum memory**.

## Trouble?
- Prism asks for Java: let it download Java 21 automatically.
- An update window appears before the game starts: that's the pack updating. Let it finish.
