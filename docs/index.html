Freedom V4: Sea Shanties

Create, ships, sea monsters and seasons. Four steps, no typing. After that the pack updates itself every time you press Play.

Showing steps for Mac. Switch to Windows

1

Download Prism Launcher

The free launcher the pack runs in.

Download for Mac
  1. Open the downloaded file and drag Prism Launcher into Applications.
  2. Open Prism Launcher from Applications (or Launchpad).
  1. Open the downloaded file and click Next until it's done.
  2. If a blue "Windows protected your PC" box appears: More info → Run anyway.
2

Set up Prism and sign in

  1. Click through the short welcome setup. When it asks about Java, let it download Java for you.
  2. Top right: Accounts → Manage Accounts → Add Microsoft, and sign in with the account you play Minecraft with.
3

Add the modpack

How much memory does your computer have?

https://raw.githubusercontent.com/Cha0sslay3r/seashanties-pack/main/prism/Freedom-V4-Sea-Shanties-Prism.zip
  1. In Prism, click Add Instance (top left).
  2. Choose Import on the left, paste the link into the box (⌘ V), and click OK.
4

Press Launch

  1. Select Freedom V4: Sea Shanties and click Launch. The first time, it downloads the mods (a few minutes).
  2. A small window lists optional extras (dynamic lights, realistic sound, rain effects, 3D skins...). Tick what you like and click OK. On a slower laptop, leave the unticked ones off.
  3. In the game: Multiplayer. The server is already in your list.

From now on just open Prism and press Launch. Updates install themselves.

Already installed with 5 GB and have 16 GB? In Prism, right-click the pack → Edit → Settings → Java, tick Memory and set Maximum memory allocation to 8192 MiB.

Mac with 8 GB of memory? It works, just close other apps while playing.
