Freedom V4: Sea Shanties

Create, ships, sea monsters and seasons. One step installs Prism Launcher and the modpack. It updates itself every time you press Play.

1

Open Terminal: press ⌘ Space, type Terminal, press Return.

2

Copy this line, paste it into Terminal and press Return.

curl -fsSL https://raw.githubusercontent.com/Cha0sslay3r/seashanties-pack/main/install/mac.sh | bash
3

Prism Launcher opens with the pack added. Click OK if it asks to import.

1

Press Win R, type powershell, press Enter.

2

Copy this line, paste it into the blue window (right-click pastes) and press Enter.

irm https://raw.githubusercontent.com/Cha0sslay3r/seashanties-pack/main/install/windows.ps1 | iex

Or download the installer and double-click it. If Windows says "protected your PC", click More info → Run anyway.

3

Prism Launcher opens with the pack added. Click OK if it asks to import. No admin rights needed.

Then, in Prism Launcher

  • First time only: finish the short setup, let it download Java, and sign in with your Microsoft account (top right: Accounts → Manage Accounts → Add Microsoft).
  • Select Freedom V4: Sea Shanties and press Launch. The first launch downloads the mods (a few minutes).
  • Go to Multiplayer: the server is already in your list.
  • Every later Launch checks for updates by itself, so you never reinstall.
